# Student Performance Multi-Class Classification

Deep learning project for multi-class classification using PyTorch.

The original code is kept unchanged in:

```text
notebook/multi class.ipynb
```

## Project Description

This notebook trains a PyTorch neural network to classify student performance levels.

Main steps included in the notebook:

- Data loading and exploration
- Missing value handling
- Exploratory data analysis
- Categorical encoding
- Feature scaling
- Class balancing using oversampling
- PyTorch multi-class classification model training
- Model evaluation using accuracy and macro F1 score
